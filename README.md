# Rewheel

Reinvent the wheel is a litle side project in response to all this AI nonesense. 
The idea is simple, build things that already exists without AI. This is the 
opposite of being productive, just go ahead and reinvent the wheel, have fun!

## Da rules

There is a couple of self imposed rules tho

1. Dont code with AI
2. Aim for something that can be done in your sparse time
3. Documentation first
4. The more Overengineering the better
5. Take as many drifts as you want
